# 🌱 TerraPulse — Touch Grass with Open-Source AI

> **Less scrolling. More exploring. More living. 🌍**

TerraPulse is an open-source AI-powered web experience built for the **Hacktoberfest Open-Source AI Challenge: Touch Grass**.

The idea is simple: instead of using AI to keep people glued to their screens, **use AI to encourage them to step away from the screen and interact with the real world.**

🌐 **[Live Demo](https://ankitkumar810.github.io/Touch-Grass-AI/)**

---

## ✨ What is TerraPulse?

TerraPulse encourages users to take a break from their digital environment and complete simple real-world activities.

It is designed for:

* 🎓 Students spending long hours studying or coding
* 💻 Developers and people working behind screens
* 📱 People who want to reduce unnecessary screen time
* 🌱 Anyone who needs a small push to go outside

The goal isn't to completely disconnect from technology.

**It's to use technology as a reason to reconnect with the world around us.**

---

## 🚀 Features

* 🌱 **Touch Grass Challenges** — Get prompted to step away from your screen.
* 🧭 **Real-World Activities** — Discover simple activities you can complete outside.
* 🤖 **AI-Powered Experience** — Uses open-source AI to create an interactive experience.
* 🌍 **Explore Your Surroundings** — Encourages users to interact with their environment.
* 📱 **Responsive Design** — Works across desktop and mobile devices.
* ⚡ **Lightweight** — Designed to be simple and fast.
* 🔓 **Open Source** — Anyone can inspect, modify, and contribute to the project.

---

## 🧠 Why AI?

AI is increasingly being used to make digital experiences more engaging.

TerraPulse asks a different question:

> **Can AI encourage us to spend less time online?**

Instead of optimizing for endless scrolling, TerraPulse uses AI as a tool for generating inspiration and encouraging real-world action.

## 🏃 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ankitkumar810/Touch-Grass-AI.git
```

### 2. Enter the project

```bash
cd Touch-Grass-AI
```

### 3. Run locally

Since this is a lightweight web project, you can open the main HTML file directly in your browser or use a local development server.

For example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
